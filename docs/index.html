Download installer (.exe) Portable zip

The installer sets up everything, including the Microsoft runtime it needs.

Install or update

  1. If the app is running, press Power OFF, then close it.
  2. Run the installer. No admin rights are needed.
  3. Open TradingPionex from the Start menu or desktop.

Your settings and history stay in %USERPROFILE%\.tradingpionex. Installing, updating or uninstalling never touches them.

Before you trade

  • Open TradingView Desktop with debug port 9222, on a chart tab with worm_10_26, spy_9_26, Heikin Ashi and 1H.
  • Enter your Pionex API key and secret in the app's Settings screen, then Save. Use a key with bot trading only, no withdrawals.
  • This app trades real money. Check it with small amounts first.
